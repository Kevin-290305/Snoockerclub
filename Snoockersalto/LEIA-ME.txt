SNOOKER CLUB SALTO — ARQUIVOS DO SITE
======================================

Esta pasta contém TODOS os arquivos do site. Não usa banco de dados,
não precisa de servidor — pode hospedar em qualquer lugar (Vercel,
Netlify, Hostinger…) ou abrir o index.html direto no navegador.

O QUE É CADA COISA
------------------
index.html ......... A página principal do site (o site inteiro está aqui)
inscricao.html ..... A página da ficha de inscrição em campeonatos
admin.html ......... O painel do clube (protegido por senha) que gera
                     o código dos campeonatos
css/style.css ...... A aparência do site inteiro (cores, tamanhos, responsivo)
js/campeonatos.js .. A LISTA DE CAMPEONATOS que aparece no site (edite aqui)
js/site.js ......... O código do botão de WhatsApp, do selo
                     "Aberto agora/Fechado agora" e das animações
img/logo-hires.jpg . A logo do clube em alta qualidade
img/clube-*.jpg .... As 4 fotos reais do clube

COMO PUBLICAR UM CAMPEONATO (sem mexer em código complicado)
-------------------------------------------------------------
1. Abra admin.html e entre com a senha do painel
2. Preencha o formulário e clique em "Gerar código do campeonato"
3. Clique em "Copiar código"
4. Abra o arquivo js/campeonatos.js no seu projeto, apague tudo,
   cole o código copiado e salve
5. Publique o site (deploy) — o campeonato já aparece na página

Para remover um campeonato: apague o bloco { ... } dele dentro do
arquivo js/campeonatos.js, salve e publique de novo.

COMO TROCAR A SENHA DO PAINEL
------------------------------
A senha fica gravada dentro do admin.html em código secreto (Base64).
Peça para gerar o código da senha nova e substitua a linha
SENHA_CODIFICADA = "..." no admin.html. Ou simplesmente me peça que eu troco.

COMO PUBLICAR NA VERCEL
------------------------
1. Acesse vercel.com → "Add New" → "Project" e envie esta pasta
   (ou envie os arquivos para o seu GitHub e importe o repositório)
2. NÃO precisa configurar variáveis de ambiente nem banco de dados
3. Depois do deploy, o painel fica em seudominio.com/admin.html

COMO TESTAR NO SEU COMPUTADOR
------------------------------
Só abrir o arquivo index.html com dois cliques — funciona direto,
inclusive o painel e a inscrição pelo WhatsApp.
